# Linux Fundamentals: Command Line From Zero

A from-scratch, beginner-friendly project that teaches the Linux command line the way you actually learn it — by building. You start with what the shell even is and how a command becomes a result, then learn to navigate the filesystem tree, read and change permissions and ownership, watch and control running processes, and wire programs together with pipes and redirection. From there you pick up the text-processing trio grep, sed, and awk, fold everything into your own shell scripts with variables, conditionals, loops, and arguments, and finish by installing software with a package manager and writing the README for the toolkit you built. Every step adds or extends a real file in a cumulative `toolkit/` you carry forward, so by the end you have a small, working set of scripts and the mental model to read and write any more.

Built step-by-step with [KhwajaLabs Build](https://khwajalabs.com).
